## Project Status

This project is currently a UI prototype of a Project Management System.
The current version focuses on dashboard design, layout, and user interface
concepts. Most interactive features are not functional yet.

## Prototype Includes

- Project Management Dashboard
- Kanban Board UI
- Timeline / Gantt Chart UI
- Sprint Planning UI
- Calendar View UI
- Team Management UI
- Notifications UI
- Reports UI
- File Attachments UI
- Project Progress Overview

## Technologies

- Python
- Flask
- HTML
- CSS
- JavaScript
